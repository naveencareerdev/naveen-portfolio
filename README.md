# Naveen A — Portfolio

## ✦ A cinematic developer portfolio

A dark, 3D-forward portfolio for Naveen A, a full-stack developer focused on
building thoughtful digital experiences, practical systems, and polished web
interfaces.

The portfolio combines expressive typography, motion, interactive 3D scenes,
and a warm blackened-teal visual system to present Naveen's work, experience,
skills, and creative approach.

## ⚙️ Tech stack

- **Next.js 15** with the App Router
- **React 18** for the interface
- **Tailwind CSS 3** for styling
- **React Three Fiber, drei, and Three.js** for interactive 3D visuals
- **Framer Motion** for transitions, reveals, and micro-interactions
- **Lenis** for smooth scrolling
- **Fraunces and Inter** via Fontsource for typography

## ✧ Experience

- Responsive portfolio sections for about, projects, experience, and contact
- Interactive 3D hero and systems visualization
- Smooth scrolling, cursor interactions, and scroll-based motion
- Reduced-motion support for a more accessible experience
- A visual language inspired by reliable systems, verified states, and creative
  problem solving
